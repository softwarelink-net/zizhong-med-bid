## 部署与运行说明

### 环境要求

- Node.js >= 18.0.0
- npm >= 9.0.0 或 pnpm >= 8.0.0

### 安装依赖

```bash
pnpm install
```

### 本地运行

```bash
pnpm dev
```

访问 [http://localhost:5173](http://localhost:5173) 查看本地开发环境。

### 演示账号

- **超级管理员**: admin / admin123
- **医务科长**: doctor_head / password123
- **普通医生**: clinician_01 / password123

### 常用脚本一览

- `pnpm dev`: 启动本地开发服务器
- `pnpm build`: 生产环境构建
- `pnpm lint`: 代码风格检查
- `pnpm preview`: 预览生产构建结果

### 摘要

资中县人民医院拟对医务管理系统进行二次竞争性谈判采购，预算金额50万元。潜在供应商需在四川省政府采购一体化平台获取文件，并于2026年09月10日09时30分前提交响应文件。项目合同履行期限为一年，要求医务管理系统开发上线后2个月内完成。不接受联合体投标。

### 技术要点

1. 系统集成能力：需与现有HIS、LIS、PACS等系统无缝对接。
2. 数据安全：符合《网络安全法》及医疗数据保密要求。
3. 移动端支持：提供便捷的移动端审批与查询功能。
4. 性能要求：支持高并发访问，保证系统稳定性。

### 技术创新性

1. 引入DRG/DIP绩效核算模型，实现精细化成本管理。
2. 基于AI的临床路径智能提醒与质控预警。
3. 全流程电子化无纸化办公，提升工作效率。
